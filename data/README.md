# Dataset information

NoshAI uses the Recipe Box dataset:

https://eightportions.com/datasets/Recipes/

Required source files:

- `recipes_raw_nosource_ar.json`
- `recipes_raw_nosource_epi.json`
- `recipes_raw_nosource_fn.json`

Place the three files in `data/raw/extracted/` before running the ingestion script.

The raw source data and generated processed database are intentionally excluded from Git.
